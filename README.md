# إدارة مزرعة العصافير — نسخة 1.7 للموبايل

## التشغيل على Android
1. ارفع مجلد البرنامج على استضافة HTTPS موثوقة (أو شغّله محليًا عبر خادم HTTPS).
2. افتح رابط `index.html` في Chrome على الهاتف.
3. من قائمة Chrome اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».
4. افتح التطبيق من الأيقونة. بعد أول تحميل يمكن استخدام الواجهة دون اتصال بالإنترنت في حدود ما تم تخزينه محليًا.

## المميزات
- واجهة عربية RTL وتصميم متجاوب للموبايل.
- سجل الطيور والأزواج والبيض والفروخ والأدوية والملفات الزمنية للطيور.
- إدارة مواسم التربية وتقارير إنتاج كل موسم: عدد الأزواج المنتجة، البيض، المخصب، الفقس، الفروخ الحية والمفطومة والنافقة.
- تسجيل المصروفات والإيرادات بالجنيه المصري، وربط الحركة بموسم، وتصنيفها.
- ملخص مالي وإنتاجي أسبوعي وشهري وسنوي أو حسب الموسم أو فترة مخصصة.
- تصدير واستيراد نسخة احتياطية JSON تشمل بيانات الطيور والإنتاج والمواسم والحركات المالية.

## تخزين البيانات
البيانات محفوظة محليًا على الهاتف داخل المتصفح (LocalStorage مع نسخة في IndexedDB). لا توجد مزامنة تلقائية بين أجهزة مختلفة أو حسابات مستخدمين أو خادم مركزي في هذه النسخة. امسح بيانات المتصفح فقط بعد التأكد من تصدير نسخة احتياطية.

## ملاحظات
- يجب استخدام HTTPS حتى يعمل التثبيت والعمل دون اتصال بصورة صحيحة.
- لا ترفع النسخة الاحتياطية إلى مكان عام؛ قد تحتوي على بيانات شخصية للمشترين.
- لم يتم إجراء اختبار اختراق أمني أو اختبار شامل على مجموعة كبيرة من الأجهزة؛ تم فحص صحة JavaScript وتكرار/وجود معرفات عناصر الصفحة فقط.
